# Deep Secure Mail Analyzer

Academic cybersecurity project focused on email threat detection and forensic analysis.

## Features

- Weighted Threat Scoring
- URL Risk Assessment
- Domain Reputation Analysis
- Attachment Inspection
- Sender Authentication Verification
- PDF Forensic Report Generation

## Technologies

- Python
- Flask
- MySQL
- Bootstrap 5
- JavaScript
- ReportLab
- Chart.js

## Installation

pip install -r requirements.txt

## Run

python app.py
