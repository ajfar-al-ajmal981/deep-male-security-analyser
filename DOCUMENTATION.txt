DEEPSECURE MAIL ANALYZER - PROJECT DOCUMENTATION
================================================

1. PROJECT OVERVIEW
-------------------
DeepSecure Mail Analyzer is a cybersecurity platform designed to protect users from email-based threats. 
It combines MIME parsing, behavioral analysis, and heuristic scoring to identify phishing, spam, and scams.

2. SYSTEM ARCHITECTURE
----------------------
- Backend: Python (Flask)
- Frontend: HTML5, CSS3, Bootstrap, Chart.js
- Database: MySQL
- Reporting: ReportLab (PDF Generation)

3. IMPLEMENTATION DETAILS
-------------------------

A. Email Parsing Engine
The system extracts data from .eml and .msg files using the `email` and `extract_msg` libraries.
Example Implementation:

B. Heuristic Scoring Logic
Threats are detected using a weighted scoring system based on keywords, URLs, and metadata.
Example Logic:
```python
score += features['urgent_words_count'] * 5
score += features['financial_terms_count'] * 8
if auth_results['spf_status'] == 'fail':
    score += 25
if features['domain_age_days'] < 30:
    score += 30
```

C. Behavioral Authentication
Checks for SPF, DKIM, and DMARC headers to verify sender legitimacy.
```python
def check_email_authentication(headers):
    auth_header = headers.get('Authentication-Results', '')
    if 'spf=pass' in auth_header.lower():
        # ... logic to update status
```

D. Domain Intelligence
Uses the WHOIS protocol to determine how long a sender's domain has been active.
```python
def check_domain_age(domain):
    w = whois.whois(domain)
    age = (datetime.now() - w.creation_date).days
    return age
```

4. CORE FEATURES
----------------
- MIME Parsing: Full extraction of headers, body, and URLs.
- Attachment Analysis: Detects dangerous extensions and double-extensions.
- Admin Dashboard: Real-time threat trends and user management.
- PDF Reporting: Professional forensic reports generated for every scan.

5. TECHNICAL STACK
------------------
- Python 3.x, Flask, PyMySQL, WHOIS, ReportLab, Bootstrap 5, Chart.js.
